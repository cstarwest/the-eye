STARTING A BRIDGE

The page answers from a mock until a bridge is linked. The bridge is a small Node server in this repository; it reads your repository through Claude Code or the Claude API.

npm install
node server.mjs                 # serves this page and picks an oracle
REPO=/path/to/repo node server.mjs   # the repository it reads

Oracles: claude-code when the claude CLI is installed and logged in; api when ANTHROPIC_API_KEY is set; mock otherwise. Force one with ORACLE=.

ORACLE=api ANTHROPIC_API_KEY=sk-ant-… node server.mjs
ORACLE=claude-code CLAUDE_PERMISSION_MODE=plan node server.mjs

Open the page the bridge serves (http://localhost:3000) and it links itself. Any other copy of the page links with ?api=http://localhost:3000, or from here. For a remote bridge, set GATEKEEPER_SECRET on the server and enter it above.
