HOW IT CONNECTS

The app runs Claude Code on this computer, in the repository you choose, with read-only tools. Nothing is served and no browser is involved.

If Claude Code is not found, install it, run claude once in a terminal to sign in, then press FIND CLAUDE CODE.

curl -fsSL https://claude.ai/install.sh | bash
npm install -g @anthropic-ai/claude-code   # or this

To answer through the Claude API instead, set ANTHROPIC_API_KEY in your shell profile, or "oracle": "api" in the settings file (File → Open Settings File). Without either, a mock answers.
